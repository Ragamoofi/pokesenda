# PokéSenda — BETA 1.0

Proyecto fan no oficial, gratuito y sin fines comerciales.

## Inicio limpio
BETA 1.0 usa un guardado nuevo. Los saves, respaldos y vínculos Cloud de las builds de desarrollo anteriores no son compatibles con esta versión.

## GitHub Pages
El archivo de entrada es `index.html`. Publica la rama `main` desde la carpeta raíz `/`.

Pokémon y sus recursos pertenecen a sus respectivos propietarios.
