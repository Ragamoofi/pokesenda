# Carrera Mundial · Prototipo web v0.1

Juego web original de carrera futbolística, inspirado en el ritmo de simulación por temporadas de Copero, pero con reglas y código propios.

## Abrir sin instalaciones
Entra a: https://ragamoofi.github.io/pokesenda/carrera-mundial/

Esta prueba está alojada temporalmente en una subcarpeta independiente de PokéSenda para no alterar su juego principal. Una vez creado el repositorio independiente se puede trasladar esta misma estructura a https://ragamoofi.github.io/carrera-mundial/.

## Contenido
- 49 nacionalidades, 166 clubes semilla, 12 posiciones
- Draft de 8 atributos, 3 ofertas iniciales del país elegido
- Simulación por temporadas, fichajes, eventos, retiro
- Autoguardado local por navegador y exportación JSON

**No es el código oficial de Copero.** Los nombres de clubes son referenciales, los resultados y las valoraciones son ficticios, y el simulador todavía no contiene calendarios ni ligas completas. Los datos y fórmulas se ampliarán en próximas versiones.
